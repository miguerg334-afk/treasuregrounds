# Treasure Grounds

Bilingual marketing website for Treasure Grounds Coffee & Bakery, built with Astro.

## Commands

| Command | Action |
| :-- | :-- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the production site in `dist/` |
| `npm run preview` | Preview the production build |

Production is deployed to Hostinger. See `DEPLOYMENT.md` for deployment notes.
